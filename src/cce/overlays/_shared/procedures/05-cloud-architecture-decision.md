title: "Cloud architecture decision"
description: "Choose and record a cloud architecture: managed services versus self-run components, cloud databases, API policies, everything-as-code, and capturing the choice as an Any Decision Record."
---

Use this procedure when deciding how a system should be built on a cloud platform and recording why. `practices/cloud-services.md` and `practices/cloud-databases.md` set the default preference for managed services; `practices/api-policies.md` covers what an exposed API must satisfy; `patterns/everything-as-code.md`, `patterns/outsource-bottom-up.md` and `patterns/architect-for-flow.md` give the reasoning behind those defaults. Capture the outcome with `any-decision-record-template.md` so the decision and its trade-offs stay with the code.
