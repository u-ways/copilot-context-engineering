description: "Publish code in the open or open-source an existing repository: licence and copyleft obligations, GitHub organisation and repository hardening, baseline visibility and code owners, secret scanning with GitLeaks, signed commits, and purging leaked secrets from history."
---

Use this procedure before making a repository public, or when open-sourcing code that already exists. `practices/open-source.md` covers licensing and what a copyleft licence obliges you to do; `practices/securing-repositories.md` and `practices/baseline-visibility.md` cover organisation and repository settings, including code ownership; `tools/gitleaks.md` covers scanning for committed secrets. The three guides under `practices/guides/` cover signing commits, signing them retrospectively, and removing a leaked secret from history; `SECURITY.md` is the framework's own example of a published disclosure policy.
