# Repository instructions

This repository is an engineering quality framework written in Markdown: principles, practices, patterns, insights and tool guides, cross-linked with relative paths.

The detailed procedures are available as Agent Skills. Consult a skill only when the task matches its description; a simple lookup does not need one.

Answer factual questions directly from the files in this repository and cite `path:line` for each fact.

Do not edit files unless the request explicitly asks for a change.
